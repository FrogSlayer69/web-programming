🎲 4. Bangla Truth or Dare System (সত্য নাকি সাহস) + 3-Day Auto-Expiry

Tables: tord_channels, tord_sessions
/tord channel:[#channel] action:[start | stop]
Interactive Game

Starts or stops the interactive Bangla Truth or Dare panel in the target channel.

🔄 Complete Button Workflow & 3-Day Auto-Delete:
1. Choose: A player clicks Truth, Dare, or Random.
2. Ask Question (প্রশ্ন করুন): Other members see who chose what along with two buttons: 📝 প্রশ্ন করুন and 🕵️ নাম/পরিচয় গোপন রাখুন (Anonymous toggle). (The player cannot ask themselves a question!)
3. Question Modal & Media Placeholder: The asker types their question, optionally pastes a Photo/GIF link in the special media placeholder field, and chooses whether to hide their identity.
4. BINGO Button: The bot posts the question, tags the player, and displays the green BINGO button. Only that specific player can click BINGO to submit their answer and proof media/GIF.
5. ⏰ 3-Day Auto-Expiry: Any Truth or Dare message older than 3 days is automatically deleted from both Discord and the Supabase database. If a user clicks a button on an expired message before cleanup, the bot sends an ephemeral expiration alert (⏰ এই Truth or Dare মেসেজটির মেয়াদ শেষ হয়ে গেছে!) and deletes the message immediately.

🏷️ 9. Auto Nickname Channel (On / Off)

Table: guild_settings
/nick state:[on | off] channel:[#channel]
Mod / Admin

Turns automatic nickname changing ON or OFF in #channel.

🤖 StickyBot-Safe & Multi-Line Smart Handling:
• Strictly ignores all bots and webhooks (such as StickyBot).
• Takes the first non-empty line of a user's message as their new nickname (supports Bangla, English, and any UTF-8 language) and reacts with ✅.
• Blocks names starting with numbers (0-9 or ০-৯) and notifies the user with ⚠️ if Discord's role hierarchy blocks changing the Server Owner's nickname.

🔗 11. Automatic Link Box Wrapper (/link)

Table: guild_settings
/link on channel:[#channel]
Mod / Admin

Turns ON automatic Link Box wrapping in #channel (can be enabled in as many channels as you want).

📦 How Link Wrapping Works: Whenever a member posts a link in an enabled channel, the bot deletes the raw message and wraps it inside a sleek Embed Box featuring the member's avatar & display name, their message text turned into a clickable hyperlink (e.g., check his shop), and a Go to Link ↗ button below it. By default, links containing discord, tenor, kliphy, klipy, or .gif are ignored so GIFs and Discord links post normally.

Adds, removes, or lists whitelisted keywords/domains that should not be wrapped into a box.

/link blacklist action:[add | remove | list] keyword_or_url:[Text]
Mod / Admin

Adds, removes, or lists blacklisted keywords/URLs that must always be wrapped into a box (overrides whitelist).

🧵 12. Silent Nested Thread Auto-Closer (Up to 15 Channels) & Timer

Tables: auto_close_channels, scheduled_thread_closes
/close channels channel1:[#ch1] channel2:[#ch2] ... channel15:[#ch15]
Mod / Admin

Configures up to 15 channels at once so that any thread opened or active inside them is silently closed (archived) without deleting the thread.

🔇 100% Silent Close (No "removed from thread" messages!):
• Immediately closes all currently open threads in the selected channels.
• Automatically re-closes threads whenever someone sends a message, edits a message, deletes a message, or reopens the thread.
• Archives threads directly without calling member-kick APIs, so Discord never displays ugly ← Bot removed User from the thread system messages inside your comment sections!
/close timer channel:[#channel] minutes:[int]
Mod / Admin

Sets a delay timer (in minutes) before newly created threads in #channel are silently closed.
