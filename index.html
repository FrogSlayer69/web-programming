📅 15. Smart Todo Routine Parser, Auto-Reminder & Activity Checker (/routine)

Tables: routine_schedules, study_users, guild_settings
/routine reminder state:[on | off] mode:[member | admin] channel:[Optional #channel (Admin)]
Member & Admin

Controls the automatic Todo Routine Reminder & Activity Checker system.

🧠 How Routine Parsing, Reminders & Activity Penalties Work:
• Member vs Admin Lock: By default, reminders are ON for everyone. Members can run /routine reminder state:on/off to toggle their own reminders. If an Admin runs /routine reminder state:off mode:admin, the feature is locked globally and members cannot turn it on until an Admin re-enables it.
• Custom Channel: By default, reminders post in the Todo channel and auto-delete after 25 seconds. Admins can change the reminder channel via /routine reminder channel:#channel.
• Smart Time Sync: When a user posts (or edits) a schedule in the Todo channel—such as Repair 9-10, Hardware 10-12, C++ 12-2, Design *-*, or 8:00 – 10:00 Web Dev—the bot parses every time slot into Supabase and confirms the sync.
• Auto-Mention & Activity Check: When the clock hits a scheduled slot in Bangladesh Time, the bot mentions the user to start that subject (and deletes the ping seconds later). During that slot's time window, if their Discord status shows an unrelated activity, they lose -1 coin; if they are playing a game during a non-game study slot, they lose a high rate of -3 coins!
